# 보안 및 안전 원칙

## GitHub에 저장할 수 있는 것

- 자동화 코드
- 개인정보를 제거한 화면 구조 기록
- 완전히 가상의 `sample.json`
- 작업 절차와 기술 문서

## 저장하거나 커밋하지 않는 것

- `.env`와 API 키
- 로그인·SSO·위임계정 정보
- 실제 과제번호, 실명, 전화번호, 이메일, 계좌번호
- 주민등록정보와 인사정보
- 실제 카드번호와 결제전표 식별정보
- 실제 증빙 PDF·HWP·HWPX·Excel 파일
- 화면 스냅샷 원본, Playwright trace, 탐색 덤프
- 실제 값이 들어간 JSON 또는 추출 결과
- 브라우저 프로필과 쿠키

실제 데이터 파일은 마스킹해서 보존하는 대신 만들지 않는 것을 원칙으로 합니다.

## 최종 처리 금지

자동화는 값을 채우고 사용자가 검토할 수 있는 상태에서 멈춥니다. 다음 버튼과 같은 효력을 가진 동작은 라벨이 달라도 자동화하지 않습니다.

- 저장
- 신청·변경신청·발급신청
- 제출·청구·승인
- 삭제·취소 확정

터미널에는 사용자가 확인해야 할 항목과 직접 수행할 최종 순서를 안내할 수 있습니다.

## 애매한 조회 결과

- 결과가 정확히 한 건이고 입력 조건과 일치할 때만 자동 선택합니다.
- 동명이인, 복수 과제, 복수 카드처럼 판단이 필요하면 멈추고 사용자가 직접 선택하게 합니다.
- 자동 선택에 실패했는데 성공한 것처럼 안내하지 않습니다.

# AIRA — 연구비 지출신청 자동화 프로토타입

서울대학교 SRnD(산학협력단 연구행정시스템)에 연구비 지출신청을 자동 입력하는
웹앱 **AIRA (AI Research Assistant)**의 클릭 가능한 UI 프로토타입입니다.

**동작 데모**: 저장소를 GitHub Pages로 배포하면 아래 주소에서 바로 열립니다.
`https://<계정명>.github.io/<저장소명>/`

## 화면 구성

| 파일 | 화면 |
|---|---|
| `index.html` | 로그인 (한국어/영어 전환) |
| `app.html` | 업무 선택 → 비목별 신청 → 자동 입력 → 완료 |

- **업무 선택**: 22개 비목을 아이콘 카드로 표시. 별(★)을 누르면 "자주 사용하는 업무"로 상단 고정 (브라우저에 저장됨). 검색·카테고리 필터 지원.
- **회의비**(현재 유일하게 활성): 클릭하면 바로 엑셀 업로드 화면. "화면에서 직접 입력" 탭으로 전환 가능. 4단계 진행 방식과 필요 서류는 우측 상단 **도움말**에서 그림으로 확인.
- **직접 입력**: 회의 일자·결제 시각에 따라 필요 증빙(사전품의서, 초과근무 확인서)이 실시간으로 갱신. 인당 금액 3만원 초과 시 경고.
- **자동 입력**: 5단계 진행 표시, 첨부파일 (n/m) 카운트와 SRnD 첨부 건수 이중 검증 표시.
- **정책**: '신청' 버튼은 자동으로 누르지 않으며, 완료 화면과 설정에 명시되어 있습니다.

## 프로토타입 범위

- 순수 HTML/CSS/JS 단일 파일 2개. 빌드 도구·서버 불필요.
- SRnD 연동, 로그인, 파일 업로드는 모두 **모의 동작**입니다. 간편인증 모달은 5초 후 자동 연결됩니다.
- 폰트(Pretendard, Material Symbols)만 CDN에서 로드합니다. 로고는 파일에 내장.

## 로컬에서 열기

`index.html`을 브라우저로 열면 됩니다. `index.html`과 `app.html`이 같은 폴더에 있어야 합니다.

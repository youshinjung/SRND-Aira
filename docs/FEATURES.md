## 상태 기준

- `미구현`: 템플릿 파일도 복사하지 않은 상태
- `조사중`: 영상·사용자 설명·화면 스냅샷을 수집하는 상태
- `테스트중`: 테스트 CMD로 실제 화면에서 검증하는 상태
- `구현완료`: 사용자가 테스트 완료를 확인했고 안전 검사를 통과한 상태

교육영상의 명칭과 실제 SRnD 화면 명칭이 다를 수 있습니다. 영상만 보고 메뉴명, 비목 코드 또는 선택자를 확정하지 말고 실제 화면 기록으로 검증해야 합니다.

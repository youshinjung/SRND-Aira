# 03 전문가활용비 모듈

## 적용 흐름

1. 사용자가 SRnD에서 `내과제관리 → 지출신청(연구자용)`으로 이동한다.
2. 사용자가 과제를 선택하고 `전문가활용비`를 눌러 지급신청 팝업을 연다.
3. 자동입력 앱에서 `전문가활용비 사용내역서` PDF를 선택한다.
4. 앱이 PDF 텍스트에서 양식의 라벨과 그 옆 또는 바로 아래 값을 읽어 `extract()`로 해석한다.
5. 모듈은 지급구분별 필수 일반항목, 기간·시간, 대면/비대면, 제목, 장소, 목적까지만 채우고 멈춘다.

## 자동화 경계

| 작업 | 처리 주체 |
|---|---|
| 로그인·위임계정 전환·과제 선택·전문가활용비 팝업 열기 | 사용자 |
| 지급구분·기간·시간·대면/비대면·제목·장소·목적 입력 | 모듈 |
| 지급 대상자 선택 및 주민번호·계좌·국적·소득 정보 확인 | 사용자 |
| 세목/비용 조회 결과 및 기준단가 선택 | 사용자 |
| 증빙서류 또는 하단 첨부파일 영역이 이미 열린 상태에서 PDF 첨부 | 모듈 |
| 증빙구분 선택·첨부 내용의 개인정보 검토 | 사용자 |
| 저장·신청·청구·승인·삭제 | 사용자 |

## PDF 양식의 라벨·영역 매핑

셀 주소나 고정 좌표는 사용하지 않는다. 표 형태 PDF는 추출 과정에서 열 순서와 줄바꿈이 달라질 수 있으므로, 아래 라벨과 **같은 줄의 값 또는 바로 아래 비어 있지 않은 값**을 읽는다.

| PDF의 대략적 위치 | 찾는 라벨 | SRnD 입력·용도 |
|---|---|---|
| 상단 기본정보 표 | `구분` | 강사료·원고료·통역료·번역료·회의수당·속기료·자문료 분기 선택 기준 |
| 상단 기본정보 표 | `대면/비대면` 또는 `진행방식` | 대면/비대면 |
| 상단 활동정보 표 | `활용일자` 또는 `활용기간` | 시작일·종료일 |
| 상단 활동정보 표 | `활용시간` | 시작·종료시간 |
| 중단 활동정보 표 | `시간/회당/장` | 구분별 수량 검증용 값 |
| 중단 활동정보 표 | `직급(직위)` | 강사료·회의수당·자문료의 직급/기준단가 구분 |
| 중단 활동정보 표 | `장소` | 장소 |
| 중단 활동정보 표 | `제목` | 제목 |
| 중단 활동정보 표 | `목적(활용내용)`·`활용내용`·`자문내용` | 목적 |
| 하단 지급내역 표 | `활용비` | 지급액 대조용 값 (자동 입력하지 않음) |

개인정보·계좌이체정보가 있는 하단 영역은 어떤 경우에도 읽거나 자동입력하지 않는다.

### 기존 `전문가 활용 내역서` PDF도 지원

기존 양식은 `일시`, `시간`, `장소`, `과제명`, `요지`, 하단 `지급금액 산출내역`의 `구분`과 `시간(원고 페이지 수)`를 같은 방식으로 읽는다. 이 양식에는 `대면/비대면`과 SRnD의 `직급/기준단가 구분`이 없을 수 있다. 해당 값은 자동으로 추정하지 않으며, 사용자가 명시해야만 화면 입력을 시작한다.

### 구분별 추가 필수값

| `구분` 값 | PDF에서 찾는 라벨 | SRnD에 채우는 항목 |
|---|---|---|
| 강사료 | `직급(직위)` | 직급/기준단가 구분 |
| 원고료 | `시간/회당/장` | 장수 검증 |
| 통역료 | `통역구분`, `언어구분`, `시간/회당/장` | 통역구분·언어구분·시간 검증 |
| 번역료 | `번역언어구분`, `시간/회당/장` | 번역언어구분·장수 검증 |
| 회의수당 | `직급(직위)`, `시간/회당/장` | 직급/기준단가 구분·회수 검증 |
| 속기료 | `속기구분`, `시간/회당/장` | 속기구분·시간 검증 |
| 자문료 | `직급(직위)`, `시간/회당/장` | 직급/기준단가 구분·시간 검증 |

라벨 또는 그 주변 값이 없으면, 모듈은 값을 추측하지 않고 빈 값으로 남긴다.

현재는 PDF마다 항목이 달라질 수 있으므로, 라벨을 찾지 못한 일반 입력값·구분별 추가값은 빈 값으로 반환한다. `fill()`은 빈 값을 입력하지 않고, PDF에서 확인된 값만 화면에 반영한다.

## 첨부파일

- `evidenceFiles`: 상단 **증빙서류** 영역에 첨부할 PDF 목록
- `bottomAttachmentFiles`: 하단 **첨부파일** 영역에 첨부할 PDF 목록

두 영역은 SRnD에서 각각 업로드 창을 연 뒤 처리한다. `attachEvidenceFiles()`와 `attachBottomAttachmentFiles()`는 이미 열린 해당 업로드 창에만 파일을 전송하며, 다른 영역으로 파일을 이동하거나 중복 첨부하지 않는다. 실제 업로드는 파일 전송 동작이므로 실행 시점에 사용자의 확인을 받는다.

## 지급대상자

- 경비지급서식이 제공되면 `경비지급 서식 업로드`를 눌러 열린 업로드 창에 `.xls`·`.xlsx`·`.xlsm` 파일을 넣는다.
- 경비지급서식이 없으면 `SRnD등록 연구자`를 선택하고, PDF 지급사항의 대상자마다 `대상자추가 → 연구원검색(멀티)`를 반복한다. 동명이인이면 PDF의 소속과 일치하는 사람만 선택한다.
- 추가된 모든 대상자 행에 PDF의 대상구분·개인지급액·항공료·교통료·체재비·숙박비 중 제공된 값만 입력한다.
- 모든 행을 체크한 뒤 수취인확인을 수행하는 기능은 실행 모드에만 존재한다. 테스트 모드에서는 이 버튼을 절대 누르지 않는다.

## 안전 규칙

- 열린 전문가활용비 팝업이 발견되지 않으면 입력하지 않고 오류로 중단한다.
- PDF에 필요한 일반 지급 정보가 없거나 화면 값 반영을 확인할 수 없으면 중단한다.
- 지급 대상자의 주민번호, 계좌, 국적, 소득·비과세 정보는 자동입력하지 않는다.
- 실제 증빙·추출 결과·개인정보·로그인 정보는 저장소에 저장하지 않는다.
- 사용내역서 PDF 첨부는 사용자가 선택한 파일과 이미 열린 첨부 창에 한정하며, 파일명 확인 후에만 완료한다.
- 저장, 신청, 변경신청, 제출, 청구, 승인, 삭제 또는 동등한 최종 동작을 하지 않는다.
